실패했습니다.

2026년 7월부터 11월까지 Claude로 하루 세 번 글을 자동 발행했습니다. 글 75편을 쌓았고, 애드센스는 세 번 거절당했습니다.

마지막에는 개별 글이 아니라 홈페이지조차 구글 색인에 들어가지 못했습니다. 11월 6일에 전부 내렸습니다.

## 어떤 구성이었나

- 호스팅: GitHub Pages + Hugo (비용 0원)
- 글 생성: Claude Code 예약 작업, 하루 3회
- 썸네일: GitHub Actions가 Gemini로 자동 생성
- 주제: 복지·세금 제도
- 발행: 사람 검토 없이 자동 머지

자동 발행이 실제로 돈 기간은 3주입니다. 7월 14일부터 8월 7일까지.

남은 3개월은 쌓인 글을 고치는 데 썼습니다.

## 3주 만에 멈췄습니다

멈춘 이유는 두 가지였습니다.

글 75편 중 구글이 색인한 것은 1편이었습니다. 7월 말부터는 크롤링도 거의 오지 않았습니다.

그리고 애드센스가 거절했습니다. 소개 페이지와 개인정보처리방침은 이미 있었고 정책 요건도 맞춰 둔 상태였습니다.

여기서 판단을 하나 했습니다. 구글 검색과 애드센스는 서로 다른 심사인데 같은 결론을 냈다는 점입니다. 그러면 설정 문제가 아니라 글 자체에 대한 평가라고 봐야 합니다.

그래서 글을 더 쌓는 것을 멈췄습니다.

## 3개월 동안 고친 것

"글을 더 좋게 만들면 풀린다"는 가정으로 움직였습니다.

- 글 75편을 43편으로 줄였습니다. 발행은 61편에서 26편으로
- 남긴 26편을 전부 심화했습니다. 자수 중앙값 3,676자 → 4,401자
- 태그 172개를 14개로 정리했습니다
- 계산기 9개를 직접 만들었습니다
- 홈을 다시 짰고, 제목 템플릿을 없앴고, 메타데이터를 전면 수정했습니다

## 결과는 같았습니다

11월 3일에 다시 넣었습니다. 거절입니다. 사유도 같았습니다.

같은 날 Search Console에서 홈페이지를 검사했더니 이렇게 나왔습니다.

| 항목 | 결과 |
| --- | --- |
| 색인 상태 | 크롤링됨 - 현재 색인이 생성되지 않음 |
| 크롤링 허용 | 예 |
| 페이지 가져오기 | 성공 |
| 참조 페이지 | 감지된 페이지 없음 |

기술 문제가 아닙니다. 구글이 와서 보고, 가져가는 데 성공하고, 색인하지 않기로 한 상태입니다.

홈까지 그렇다는 건 글 하나하나에 대한 판정이 아니라 사이트 전체에 대한 판정이라는 뜻입니다.

여기서 가정이 깨졌습니다. 할 수 있는 걸 다 하고도 같은 답이 돌아왔으니까요.
