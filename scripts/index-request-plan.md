# 구글 색인 요청 계획

Search Console → **URL 검사**에 아래 주소를 하나씩 넣고 **색인 생성 요청**을 누른다.
하루 한도가 대략 10~15개이므로 날짜별로 끊어 두었다. 요청해도 색인은 보장되지 않고,
같은 URL을 반복 요청하는 것은 효과가 없다.

**사이트맵도 제출돼 있는지 먼저 확인한다** (Search Console → 사이트맵 → `sitemap.xml`).

## 우선순위를 이렇게 잡은 이유

- **계산기가 1순위다.** 공식 사이트에 없는 도구이고, 이 사이트에서 가장 고유한 자산이다.
  색인될 가능성이 가장 높고 색인되면 검색 유입으로 바로 이어진다.
- 글은 **비교형과 검색 수요가 큰 제도**를 앞에 뒀다.
- 분류 아카이브는 요청하지 않는다. 본문이 없는 목록 페이지다.

## 요청 뒤에 볼 것

- **색인 생성 요청 ≠ 색인.** 며칠 뒤 같은 URL을 URL 검사에 다시 넣어 상태를 본다.
- `크롤링됨 - 현재 색인이 생성되지 않음`이 나오면 **구글이 보고 나서 색인을 안 한 것**이다.
  기술 문제가 아니라 품질·중복 판단이므로 요청을 더 해도 바뀌지 않는다.
- `검색된 - 현재 색인이 생성되지 않음`이면 아직 안 본 것이므로 기다릴 가치가 있다.
- 네이버 서치어드바이저에도 같은 목록으로 **웹 페이지 수집 요청**을 넣는다.
  네이버는 신규 사이트에 구글보다 관대하고, 이미 사이트 등록은 돼 있다.
