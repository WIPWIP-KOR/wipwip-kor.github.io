# 유입 확보 계획 (2026-11-03)

애드센스 3차 거절 뒤 방향을 바꿨다. **애드센스 재심사는 보류하고, 실제 유입을 먼저
만든다.** 승인이 나도 유입이 0이면 수익이 0이기 때문이다.

## 지금 상태 (측정값, 2026-11-03)

| 채널 | 상태 |
| --- | --- |
| 구글 | **홈페이지조차 색인 안 됨** — "크롤링됨 - 현재 색인이 생성되지 않음" |
| 구글 사이트맵 | Search Console이 "감지된 참조 사이트맵이 없습니다"로 표시 |
| 네이버 | **서치어드바이저에 등록조차 안 돼 있다** (`naverSiteVerification`이 빈 값) |
| 빙 | 등록 안 됨 (`bingSiteVerification`이 빈 값) |

**구글은 막혀 있고 네이버는 시작조차 안 했다.** 구글의 "크롤링됨 - 색인 생성되지 않음"은
구글이 보고 나서 색인하지 않기로 한 상태이므로 색인 요청을 더 해도 바뀌지 않는다
(`index-request-plan.md` 참고). 홈까지 그 상태라는 것은 개별 글 판정이 아니라 **사이트
전체에 대한 판정**이라는 뜻이다.

그래서 **열려 있는 문은 네이버와 빙 쪽이다.** 둘 다 신규 사이트에 구글보다 관대하고,
이 블로그의 주제(복지·세금·지원금)는 한국 검색에서 네이버 비중이 크다.

## 사람이 해야 하는 것 (Claude가 못 한다)

### 1. 네이버 서치어드바이저 등록 — 우선순위 1

- [x] <https://searchadvisor.naver.com> → **웹마스터 도구** → 사이트 추가
- [x] `https://wipwip-kor.github.io/` 입력
- [x] 소유확인 방법 **HTML 태그** 선택, 코드 발급
- [x] **2026-11-03 — 인증 코드를 `hugo.toml`의 `naverSiteVerification`에 넣고 배포했다.**
      전 페이지(60/60)에 `<meta name="naver-site-verification">`이 나간다
- [ ] 서치어드바이저에서 **소유확인** 버튼 누르기 ← **다음 할 일**
- [ ] 확인되면 **요청 → 사이트맵 제출**에 `https://wipwip-kor.github.io/sitemap.xml`
- [ ] **요청 → RSS 제출**에 `https://wipwip-kor.github.io/index.xml`
- [ ] **요청 → 웹 페이지 수집**에 URL을 하나씩 넣는다 (`index-request-plan.md`의 목록을
      쓴다. 계산기 먼저, 분류 아카이브는 제외)

> 소유확인은 GitHub Pages 배포가 끝난 뒤에 눌러야 한다. 푸시하고 1~3분쯤 걸린다.
> 홈에서 메타태그가 보이는지 먼저 확인하면 실패를 줄일 수 있다.
>
> 확인 뒤에도 **메타태그를 지우면 안 된다.** 네이버는 주기적으로 소유권을 재확인한다.

### 2. 구글 Search Console 사이트맵 제출 확인 — 우선순위 2

홈 URL 검사에 "감지된 참조 사이트맵이 없습니다"가 나왔다. **Search Console → 사이트맵**에서
`sitemap.xml`이 "성공" 상태로 제출돼 있는지 확인한다.

- 제출돼 있지 않으면 제출한다
- 이미 "성공"이면 그대로 둔다. 이 문구는 구글이 해당 URL을 사이트맵 경유로 발견한 기록이
  없을 때도 나오므로, 그 자체가 반드시 미제출을 뜻하지는 않는다
- **단, 사이트맵을 제출해도 "크롤링됨 - 색인 생성되지 않음"은 풀리지 않는다.** 이건 발견
  경로 문제가 아니라 품질 판정이다. 사이트맵은 해 두는 게 맞지만 기대를 걸 대상은 아니다

## 다음에 볼 지표

애드센스 승인이 아니라 아래를 본다.

| 지표 | 현재 | 의미 |
| --- | --- | --- |
| 네이버 등록 여부 | 미등록 | 가장 먼저 바꿀 것 |
| 네이버 수집된 페이지 수 | 0 | 서치어드바이저에서 확인 |
| 구글 색인 페이지 수 | 2 (홈 제외) | 네이버 유입이 생기면 따라 오를 수 있다 |
| 실제 방문자 | 사실상 0 | 유입이 생기는지의 유일한 증거 |

구글 색인을 네 번째 지표로 둔 이유는, **외부에서 실제 방문이 생기면 구글의 품질 판정이
바뀔 여지가 있기 때문이다.** 반대 순서(색인 → 방문)는 두 달 동안 시도해서 안 됐다.
